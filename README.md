# EasyVenue 🏟️  
Mini Venue Booking Platform

EasyVenue is a **full-stack web application** developed using **Java Spring Boot** and **React**.  
The project allows users to browse and book venues, while admins can manage venues and view bookings.

> 📌 This project is built for **learning and academic practice** to understand full-stack application development.

---

## ✨ Features

### 👥 User Features
- View list of available venues
- See venue details (location, capacity, price)
- Book a venue for a selected date
- View booking confirmation

### 🛠 Admin Features
- Add new venues
- Update venue availability
- View all venues
- View recent bookings
